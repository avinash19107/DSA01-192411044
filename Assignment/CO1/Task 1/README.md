## Main design decisions
- `SmartCard` owns and protects the stored balance.
- `Passenger` stores the passenger category used to determine concession eligibility.
- `Journey` stores the farthest zone and entry time.
- `Zone` and `Category` are represented using scoped enumerations (`enum class`).
- `FareTable` centralises base fares, surcharge and concession rules.
- Money is represented as integer paise to avoid floating-point rounding errors.
- A journey is accepted only when the remaining balance is at least Rs 50.

## Assumptions
The assignment states that students and senior citizens receive a concession but does not specify its percentage. The current answer uses a 50% concession as an explicit working assumption. Confirm the percentage with the faculty if an official value is provided.

The peak windows are interpreted as [08:00, 10:00) and [17:00, 20:00): 08:00 and 17:00 are peak; 10:00 and 20:00 are off-peak.

## Complexity
- Time per journey: O(1) in both procedural and object-oriented designs because each journey requires a fixed number of operations.
- Memory per card: O(1) in both designs because each card stores a fixed amount of state.
- The object-oriented design improves encapsulation and rule ownership; it does not change the asymptotic complexity.
