# Task 05 – Operators and Precedence

`t5.cpp` is the assignment's Predict-the-Output program. `t5_inc.cpp` demonstrates post-increment, pre-increment and the unsafe `i = i++` expression.

Compile:
```bash
g++ -std=c++17 -Wall -Wextra t5.cpp -o t5
./t5
g++ -std=c++17 -Wall -Wextra t5_inc.cpp -o t5_inc
./t5_inc
```
Write the predicted output before execution. Treat any warning/behaviour of `i = i++` according to the C++ standard and compiler version.
