# Task 08 – Safe Input and Output

Contains the gate input program, a shared `core.h`, an input sample and a getline/stoi alternative demonstration.

Compile:
```bash
g++ -std=c++17 -Wall -Wextra gate_input.cpp -o gate_input
./gate_input < t8.in
g++ -std=c++17 -Wall -Wextra getline_stoi.cpp -o getline_stoi
./getline_stoi
```
Test invalid letters, negative journey counts, invalid zones and boundary times. Capture your own output.
