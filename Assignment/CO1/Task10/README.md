# Task 10 – Compare Expectations with Execution

`t10.cpp` accepts actual fare values in paise and compares integer-paise, double and float accumulation. It deliberately avoids inventing a zone/peak/concession distribution: feed it the fare sequence generated by your Task 9 or your own deterministic journey generator.

Compile:
```bash
g++ -std=c++17 -Wall -Wextra t10.cpp -o t10
./t10 < fares_paise.txt
```
Create `fares_paise.txt` from the journey set you actually used. Record totals for 20,000, 500,000 and 3,000,000 journeys. Do not rely on signed-int wraparound; signed overflow is undefined behaviour.
