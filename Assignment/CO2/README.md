# DSA01 – Assignment 2 (CO2)

C++ practical implementations for Q1–Q7 covering parameter passing, reference returns, default arguments, function overloading, classes with arrays, static members, arrays of objects, friend functions and inline functions, and a measured redesign.

## Repository layout

```text
Task01/  Call by value, reference and pointer
Task02/  Return by reference and dangling references
Task03/  Default arguments and function overloading
Task04/  Savings account with transaction array
Task05/  Static members and bus ticket objects
Task06/  Friend functions and inline benchmark
Task07/  Design diagnosis and circular-buffer redesign
```

Each task folder contains C++ source files, a short task README, and execution screenshots in `screenshots/`.

## Compiler

The programs use standard C++17 and were compiled in Kali Linux with GNU g++ using `-std=c++17 -Wall -Wextra`. Benchmarks use the optimization flags stated in Task06 and Task07.
