# CO3 Assignment 3 – C++ Constructors, Destructors and Operator Overloading

This repository contains source files, task-specific README files and available terminal screenshots for Q1–Q7.

## Build
Compiler used in the captured terminal sessions: GNU g++ with C++17.
General build command: `g++ -std=c++17 -Wall -Wextra source.cpp -o program`
For AddressSanitizer tests: `g++ -std=c++17 -Wall -Wextra -g -fsanitize=address -fno-omit-frame-pointer source.cpp -o program`

## Task folders
- Task01: Constructors and constructor overloading
- Task02: Shallow and deep copies
- Task03: Dynamic constructors and destructors
- Task04: Money arithmetic and stream operators
- Task05: Increment, comparison and subscript operators
- Task06: Text class and operator-overloading rules
- Task07: Complex-number and AC impedance calculator

## Evidence note
The screenshots are terminal captures supplied during the practical work. Timing results are machine- and run-dependent. The `std::string` benchmark reported 0 ms at millisecond resolution; this means the measured time was below the displayed resolution, not literally zero.
